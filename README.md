# ERMA-7310: Class Project
## Author: Muhtarin Khayer Brohee
### Project title: Health Expenditure and Child Malnutrition

This project examines the association between national health expenditure and child malnutrition outcomes across countries from 2016 to 2022.

The analysis uses country-level data from the World Bank Health, Nutrition, and Population database. The main outcomes are:

- Stunting among children under five
- Severe wasting among children under five
- Underweight among children under five

Current health expenditure as a percentage of GDP is the main predictor. Other variables include GNI per capita, basic sanitation, urban population, adolescent fertility, and female secondary-school enrollment.

The final dataset contains 1,519 country-year observations from 217 countries. Statistical analyses were completed in R and included descriptive statistics, correlation analysis, multiple linear regression, one-way ANOVA, MANOVA, Welch t-tests, and interaction models.

The results showed that, after adjustment, health expenditure was significantly associated with lower severe wasting and underweight but was not significantly associated with stunting. Malnutrition outcomes also differed significantly across income groups, development-status groups, and world regions.

This repository contains the cleaned dataset, R analysis code, figures, statistical output, and final project paper.
